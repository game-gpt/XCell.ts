# XCell 示例

本目录包含 XCell 配置表管理工具的示例配置表，涵盖不同游戏类型的数据表设计。每个示例都是独立的项目，包含 `ProjectSettings.toml` 配置文件和若干 CSV 数据表，可直接使用 XCell CLI 生成代码。

## 示例总览

| 示例名称 | 游戏类型 | 表格数量 | 主要特性 | 推荐场景 |
|----------|----------|----------|----------|----------|
| [galgame](galgame/) | 视觉小说/恋爱游戏 | 8 | `@text` 唯一名称、分支剧情、好感度系统 | 剧情驱动游戏、对话系统设计 |
| [mmorpg](mmorpg/) | 大型多人在线 RPG | 14 | `datetime`、`time`、`color`、`HashMap`、套装系统 | 复杂配置系统、MMO 游戏开发 |
| [roguelike](roguelike/) | Roguelike | 10 | `vec2<i32>`、事件链、遗物系统、卡牌战斗 | 随机地牢、卡牌战斗游戏 |

## 快速上手

### 1. 选择示例

选择一个示例目录作为工作空间，例如：

```
cd examples/rpg
```

### 2. 运行 XCell

在示例目录下运行 XCell CLI：

```bash
xcell.exe
```

XCell 会自动扫描当前目录下的 CSV 文件，验证数据并生成代码。

### 3. 指定工作空间

也可以通过 `--workspace` 参数指定示例目录：

```bash
xcell.exe --workspace examples/rpg
```

### 4. 仅检查配置表

使用 `check` 命令验证配置表数据，不导出文件：

```bash
xcell.exe check
```

### 5. 监听模式

启用监听模式，文件修改时自动重新生成：

```bash
xcell.exe --watch
```

## CSV 格式说明

示例中的 CSV 文件采用两行表头格式：

### @list 格式（列表表）

```csv
@list,name,description,type,cost
id,text,text,text,i32
1,火球术,发射火球造成伤害,攻击,30
2,治疗术,恢复目标生命值,治疗,20
```

- **第 1 行**：`@list` 标记 + 字段名称（英文）
- **第 2 行**：`id` 标记 + 字段类型
- **第 3 行起**：数据行

### @enum 格式（枚举表）

```csv
@enum,id,name,color
name,i32,text,color
Common,1,普通,#FFFFFF
Rare,2,稀有,#0070DD
```

- **第 1 行**：`@enum` 标记 + 字段名称
- **第 2 行**：`name` 标记（枚举键类型）+ 字段类型
- **第 3 行起**：数据行

### @class 格式（全局配置表）

```csv
@class,@comment,@type,@default
max_level,最大等级,i32,50
exp_multiplier,经验倍率,f32,1.5
```

- **第 1 行**：`@class` 标记 + 固定列头 `@comment`、`@type`、`@default`
- **第 2 行起**：每行一个配置项，包含字段名、注释、类型和默认值

### 常用字段类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `i32` / `u32` | 整数 | `100` |
| `f32` | 浮点数 | `1.5` |
| `text` | 字符串 | `火球术` |
| `bool` | 布尔值 | `true` / `false` |
| `&Table` | 外键引用 | `&Skills` |
| `[&Table]` | 引用列表 | `[&Skills]` |
| `[(&T, V)]` | 元组列表 | `[(&Cards, i32)]` |
| `vec2<T>` | 2D 向量 | `(3, 5)` |
| `vec3<T>` | 3D 向量 | `(3.0, 0.0, 3.0)` |
| `time` | 时间 | `15s` |
| `datetime` | 日期时间 | `2024-01-01 12:00:00` |
| `color` | 颜色 | `#FF0000` |
| `HashMap<K,V>` | 哈希映射 | `金币=500,经验=1000` |
| `EnumName` | 枚举引用 | `Common` / `Rare` |
