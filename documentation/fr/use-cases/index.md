## Descriptions des cas

### Intégration Unity

Adapté aux développeurs utilisant le moteur Unity pour le développement de jeux. Ce cas détaille comment intégrer de manière transparente l'outil de gestion de tables de configuration XCell avec des projets Unity, y compris :

- Configuration du projet Unity
- Création et gestion de tables de configuration
- Génération de code C#
- Chargement de données binaires
- Exemples d'utilisation à l'exécution
