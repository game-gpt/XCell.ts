## Case Descriptions

### Unity Integration

Suitable for developers using the Unity engine for game development. This case details how to seamlessly integrate the XCell configuration table management tool with Unity projects, including:

- Unity project configuration
- Configuration table creation and management
- C# code generation
- Binary data loading
- Runtime usage examples
