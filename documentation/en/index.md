# XCell Documentation

Welcome to the XCell documentation. XCell is a configuration table management tool written in Rust, designed for game development and multi-platform data management.

- [Overview](overview/index.md) - Learn about XCell's core features, including table types (dict, list, enum, class, language), code generation targets, type system, table merge, and configuration system

- [Advanced](advanced/index.md) - Deep dive into XCell's internal mechanisms, including the type system, field constraints, reference types, meta attributes, configuration files, and extensibility

- [Use Cases](use-cases/index.md) - Practical examples and best practices for integrating XCell with different game engines and frameworks
