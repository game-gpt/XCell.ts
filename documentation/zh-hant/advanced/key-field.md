# 欄位約束

欄位約束用於限制欄位值的規則，確保資料的唯一性和完整性。

## 唯一约束（unique）

唯一约束確保欄位值不能重復。

### 標記方式

| 便捷寫法   | 元屬性寫法         | 說明         |
| ------ | ------------- | ---------- |
| `@欄位名` | `欄位名 @unique` | 唯一欄位，值不能重復 |

### 範例

| @dict     | 名稱     | 郵箱                     |
| --------- | ------ | ---------------------- |
| user\_id  | name   | @email                 |
| string    | string | string                 |
| user\_001 | 張三     | <zhangsan@example.com> |
| user\_002 | 李四     | <lisi@example.com>     |

- `@email` - 郵箱欄位值不能重復

## 主鍵约束（primary）

主鍵是資料表中用於唯一標識每一行資料的欄位。

### 預設規則

- **第一列自動视為主鍵**，无需額外標記

### 標記方式

| 便捷寫法    | 元屬性寫法          | 說明            |
| ------- | -------------- | ------------- |
| `@@欄位名` | `欄位名 @primary` | 主鍵欄位，值唯一且作為主鍵 |

### 範例

| @dict      | 名稱     |
| ---------- | ------ |
| @@item\_id | name   |
| string     | string |
| sword\_001 | 铁劍     |
| sword\_002 | 精钢劍    |

- `@@item_id` - 主鍵欄位，值唯一

## 復合约束

當多個欄位组合起来必须唯一时，可以使用復合约束。在類型標記後新增 `@unique(field1, field2)`：

| @dict @unique(class, level) | 职業      | 等级    |
| --------------------------- | ------- | ----- |
| id                          | class   | level |
| string                      | string  | i32   |
| warrior\_001                | warrior | 10    |
| warrior\_002                | warrior | 20    |
| mage\_001                   | mage    | 10    |

上述範例中，`职業 + 等级` 组合必须唯一，但單独的职業或等级可以重復。

> ⚠️ **警告**：如果使用了復合唯一约束，那麼參照该資料表时 `&T` 也要填複合鍵。部分遊戲引擎並不支援複合鍵，请谨慎使用。

## 约束要求

- 主鍵值必须唯一
- 主鍵值不能為空
- 每張資料表只能有一個主鍵
- 唯一欄位值不能重復
