# 字段约束

字段约束用于限制字段值的规则，确保数据的唯一性和完整性。

## 唯一约束（unique）

唯一约束确保字段值不能重复。

### 标记方式

| 便捷写法   | 元属性写法         | 说明         |
| ------ | ------------- | ---------- |
| `@字段名` | `字段名 @unique` | 唯一字段，值不能重复 |

### 示例

| @dict     | 名称     | 邮箱                     |
| --------- | ------ | ---------------------- |
| user\_id  | name   | @email                 |
| string    | string | string                 |
| user\_001 | 张三     | <zhangsan@example.com> |
| user\_002 | 李四     | <lisi@example.com>     |

- `@email` - 邮箱字段值不能重复

## 主键约束（primary）

主键是表中用于唯一标识每一行数据的字段。

### 默认规则

- **第一列自动视为主键**，无需额外标记

### 标记方式

| 便捷写法    | 元属性写法          | 说明            |
| ------- | -------------- | ------------- |
| `@@字段名` | `字段名 @primary` | 主键字段，值唯一且作为主键 |

### 示例

| @dict      | 名称     |
| ---------- | ------ |
| @@item\_id | name   |
| string     | string |
| sword\_001 | 铁剑     |
| sword\_002 | 精钢剑    |

- `@@item_id` - 主键字段，值唯一

## 复合约束

当多个字段组合起来必须唯一时，可以使用复合约束。在类型标记后添加 `@unique(field1, field2)`：

| @dict @unique(class, level) | 职业      | 等级    |
| --------------------------- | ------- | ----- |
| id                          | class   | level |
| string                      | string  | i32   |
| warrior\_001                | warrior | 10    |
| warrior\_002                | warrior | 20    |
| mage\_001                   | mage    | 10    |

上述示例中，`职业 + 等级` 组合必须唯一，但单独的职业或等级可以重复。

> ⚠️ **警告**：如果使用了复合唯一约束，那么引用该表时 `&T` 也要填复合键。部分游戏引擎并不支持复合键，请谨慎使用。

## 约束要求

- 主键值必须唯一
- 主键值不能为空
- 每张表只能有一个主键
- 唯一字段值不能重复
