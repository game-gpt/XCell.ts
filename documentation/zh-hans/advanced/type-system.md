# 类型系统（Type System）

XCell 支持多种数据类型，标准类型采用 Rust 约定，同时兼容 C 约定和 C++ 约定。类型不区分大小写。

## 基本类型

### 整数类型

| 标准写法  | Unity 约定             | Unreal 约定  | 描述       | 范围                                         |
| ----- | -------------------- | ---------- | -------- | ------------------------------------------ |
| `i8`  | `char`               | `int8_t`   | 8位有符号整数  | -128 到 127                                 |
| `u8`  | `unsigned char`      | `uint8_t`  | 8位无符号整数  | 0 到 255                                    |
| `i16` | `short`              | `int16_t`  | 16位有符号整数 | -32768 到 32767                             |
| `u16` | `unsigned short`     | `uint16_t` | 16位无符号整数 | 0 到 65535                                  |
| `i32` | `int`                | `int32_t`  | 32位有符号整数 | -2147483648 到 2147483647                   |
| `u32` | `unsigned int`       | `uint32_t` | 32位无符号整数 | 0 到 4294967295                             |
| `i64` | `long long`          | `int64_t`  | 64位有符号整数 | -9223372036854775808 到 9223372036854775807 |
| `u64` | `unsigned long long` | `uint64_t` | 64位无符号整数 | 0 到 18446744073709551615                   |

<br />

### 浮点数类型

| 标准写法  | C 约定     | C++ 约定   | 描述     | 精度  |
| ----- | -------- | -------- | ------ | --- |
| `f32` | `float`  | `float`  | 32位浮点数 | 单精度 |
| `f64` | `double` | `double` | 64位浮点数 | 双精度 |

### 布尔类型

| 标准写法   | C 约定   | C++ 约定 | 描述  | 值                |
| ------ | ------ | ------ | --- | ---------------- |
| `bool` | `bool` | `bool` | 布尔值 | `true` 或 `false` |

### 字符类型

| 标准写法    | 描述          |
| ------- | ----------- |
| `utf8`  | UTF-8 字符类型  |
| `utf16` | UTF-16 字符类型 |

### 字符串类型

| 标准写法     | 描述                 |
| -------- | ------------------ |
| `string` | 字符串类型              |
| `str`    | 字符串类型（与 string 等效） |

## 复合类型

### 数组与向量类型

**不同类型的约定**：

| 标准写法        | C# 约定            | 描述         |
| ----------- | ---------------- | ---------- |
| `[T]`       | `T[]`            | 动态数组       |
| `[T; N]`    | `T[N]`           | 静态数组（固定大小） |
| `Vec<T>`    | `List<T>`        | 向量/列表类型    |
| `vec2<f32>` | `Vector2<float>` | 2D向量       |
| `vec3<f32>` | `Vector3<float>` | 3D向量       |
| `vec4<f32>` | `Vector4<float>` | 4D向量       |

**说明**：

- 动态数组 `[T]` 和向量 `Vec<T>` 用于存储可变数量的元素
- 静态数组 `[T; N]` 用于存储固定数量的元素，长度在定义时确定
- 特殊向量类型（vec2/vec3/vec4）在图形编程中常用，Unity 等引擎会有特定的性能优化

**示例**：

- `[i32; 5]` - 包含5个i32元素的静态数组
- `[string]` - 动态大小的字符串数组
- `Vec<i32>` - 整数向量
- `vec3<f32>` - 3D浮点向量

### 字典类型

**格式**：`HashMap<K, V>` 或 `dict<K, V>`

**示例**：

- `HashMap<string, i32>` - 字符串到整数的映射
- `dict<i32, string>` - 整数到字符串的映射

### 元组类型

**格式**：`(T1, T2, ...)`

**示例**：

- `(i32, string)` - 包含整数和字符串的元组
- `(f32, f32, bool)` - 包含两个浮点数和一个布尔值的元组

## 特殊类型

### 颜色类型

| 类型      | 描述               | 格式                  |
| ------- | ---------------- | ------------------- |
| `color` | 颜色类型             | 十六进制颜色值，如 `#FF0000` |
| `Color` | 颜色类型（与 color 等效） | 十六进制颜色值，如 `#FF0000` |

| 类型         | 描述     | 格式                                  |

| `time`     | 时间类型   | 如 `10:30:00`                        |
| `date`     | 日期类型   | 如 `2023-12-25`                      |

## 独一类型与主键

**独一类型格式**：

- `@T` - 表示该字段的值在表中必须唯一，即表中不能有两行数据在该字段上有相同的值
- `@@T` - 表示该字段的值在表中必须唯一且作为主键

**主键说明**：

- 主键是表中用于唯一标识每一行数据的字段
- 如果表中没有使用 `@@T` 显式标记主键，那么表的第一列会自动被视为主键
- 主键值必须唯一且非空，用于在表之间建立关联关系

**示例**：

- `@@i32` - 整数类型的主键字段
- `@string` - 字符串类型的唯一字段（非主键）

## 自定义类型

### 枚举类型

通过 Enumerate 表格定义的枚举类型可以在其他表格中使用。

**示例**：

- `QualityType` - 引用枚举表中定义的品质类型

### 结构体类型

通过 Class 表格定义的结构体类型可以在其他表格中使用。

**示例**：

- `Position` - 引用 Class 表格中定义的位置结构体

## 类型转换

XCell 支持自动类型转换，例如：

- 整数可以自动转换为浮点数
- 浮点数在需要时可以转换为整数（会截断小数部分）
- 数字可以转换为字符串
- 字符串可以在适当情况下转换为数字

## 类型验证

XCell 在解析表格时会进行类型验证，确保数据符合指定的类型要求。如果类型不匹配，会在编译时生成错误。
