## Описание вариантов

### Интеграция с Unity

Подходит для разработчиков, использующих движок Unity для разработки игр. Этот вариант подробно описывает, как бесшовно интегрировать инструмент управления конфигурационными таблицами XCell с проектами Unity, включая:

- Конфигурацию проекта Unity
- Создание и управление конфигурационными таблицами
- Генерацию кода C#
- Загрузку бинарных данных
- Примеры использования во время выполнения
