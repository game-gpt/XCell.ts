# Возможности XCell

## Типы таблиц

| Тип | Описание |
| ---- | ----------- |
| Таблица dict | Строковый первичный ключ, наиболее распространённая форма конфигурации |
| Таблица list | Целочисленный первичный ключ, последовательный доступ |
| Таблица enum | Тип перечисления с дополнительными данными |
| Таблица class | Глобальный класс конфигурации, паттерн одиночка |
| Таблица language | Поддержка многоязычности |

## Система типов

### Базовые типы

| Тип | Описание |
| ---- | ----------- |
| `bool` | Логическое значение |
| `i8`, `i16`, `i32`, `i64` | Знаковые целые числа |
| `u8`, `u16`, `u32`, `u64` | Беззнаковые целые числа |
| `f32`, `f64` | Числа с плавающей точкой |
| `string` | Строка |

### Составные типы

| Тип | Описание |
| ---- | ----------- |
| `[T]` | Динамический массив |
| `[T; N]` | Статический массив |
| `Vec<T>` | Вектор/Список |
| `vec2`, `vec3`, `vec4` | Векторные типы |
| `HashMap<K, V>` | Тип словаря |

### Специальные типы

| Тип | Описание |
| ---- | ----------- |
| `color` | Тип цвета |
| `datetime`, `time`, `date` | Типы времени |
| `&T` | Ссылочный тип |

## Функция слияния таблиц

- **Соглашение об именовании**: Имена с подчёркиваниями сливаются автоматически, например `Item_Weapon` + `Item_Armor` → `Item`
- **Правила слияния**: Таблицы с одинаковой структурой сливаются автоматически, дублирование ID вызывает ошибки
- **Зарезервированное имя таблицы**: `Language` является зарезервированным именем таблицы

## Система конфигурации

- **Конфигурация проекта**: `XCell.toml` в корне проекта
- **Конфигурация таблицы**: Файл `.toml` с тем же именем
- **Маппинг строк**: Поддержка миграции устаревших таблиц

## Архитектура

```
xcell-provider (Чтение/Запись таблиц)
    → xcell-analyzer (Анализ таблиц)
    → xcell-generator (Генерация кода)
    → xcell (CLI-инструмент)
```

## Основные модули

| Модуль | Функция |
| ------ | -------- |
| xcell-types | Определения системы типов |
| xcell-provider | Интерфейсы чтения/записи таблиц |
| xcell-parser | Синтаксический анализатор |
| xcell-analyzer | Анализатор таблиц |
| xcell-config | Управление конфигурацией |
| xcell-generator | Генератор кода |
| xcell-plugin | Система плагинов |
| xcell | Инструмент командной строки |
