# Интеграция с XLua

XLua — это часто используемое решение для скриптов Lua в Unity. XCell обеспечивает поддержку интеграции с XLua.

## Маппинг типов

| Тип XCell | Тип XLua | Описание |
| ---------- | --------- | ----------- |
| `i8` | `number` | 8-битное знаковое целое |
| `i16` | `number` | 16-битное знаковое целое |
| `i32` | `number` | 32-битное знаковое целое |
| `i64` | `number` | 64-битное знаковое целое |
| `u8` | `number` | 8-битное беззнаковое целое |
| `u16` | `number` | 16-битное беззнаковое целое |
| `u32` | `number` | 32-битное беззнаковое целое |
| `u64` | `number` | 64-битное беззнаковое целое |
| `f32` | `number` | 32-битное число с плавающей точкой |
| `f64` | `number` | 64-битное число с плавающей точкой |
| `bool` | `boolean` | Логическое значение |
| `string` | `string` | Строка |
| `array<T>` | `table` | Массив |
| `map<K, V>` | `table` | Отображение |
| `enum` | `number` | Перечисление |
| `struct` | `table` | Структура |

## Шаги интеграции

1. **Установка XLua**: Установите плагин XLua в проекте Unity
2. **Настройка XCell**: Включите генерацию кода XLua в конфигурации проекта
3. **Генерация кода**: Используйте XCell для генерации кода, совместимого с XLua
4. **Загрузка данных**: Загрузите сгенерированные данные в скриптах Lua

## Пример кода

```lua
-- Загрузка конфигурационных данных
local config = require("ConfigManager")

-- Доступ к конфигурации
local playerConfig = config.Player[1]
print("Имя игрока: " .. playerConfig.name)
print("Уровень игрока: " .. playerConfig.level)
```

## Примечания

- Типы чисел XLua унифицированы как `number`, что может привести к потере точности
- Сложные структуры данных будут преобразованы в таблицы Lua
- Рекомендуется использовать LuaJIT для лучшей производительности
