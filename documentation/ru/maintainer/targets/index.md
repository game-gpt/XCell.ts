# Целевые платформы

XCell поддерживает несколько целевых платформ, включая фронтенд и бэкенд. В этой главе подробно описаны методы интеграции и маппинг типов для каждой платформы.

## Фронтенд-платформы

Фронтенд-платформы в основном ориентированы на игровые движки и фронтенд-фреймворки, предоставляя функциональность генерации кода и загрузки данных.

### Игровые движки

- [Unity](unity.md) - Интеграция с движком Unity ⚠️ (в настоящее время отключена)
- [Cocos](cocos.md) - Интеграция с движком Cocos ✅
- [Unreal Engine](unreal.md) - Интеграция с Unreal Engine
- [Godot](godot.md) - Интеграция с движком Godot
- [XLua](xlua.md) - Интеграция со скриптами XLua

### Фронтенд-фреймворки

- [React](react.md) - Интеграция с фреймворком React
- [Vue](vue.md) - Интеграция с фреймворком Vue
- [TypeScript/JavaScript](typescript.md) - Интеграция с TypeScript/JavaScript ✅

## Бэкенд-платформы

Бэкенд-платформы в основном ориентированы на серверную часть и хранение данных, предоставляя персистентность данных и серверную интеграцию.

### Форматы данных

- [JSON](json.md) - Формат данных JSON ✅
- [SQL](sql.md) - Интеграция с базой данных SQL

## Описание статуса генераторов кода

| Генератор | Статус | Описание |
| --------- | ------ | ----------- |
| `json` | ✅ Доступен | Генерация данных JSON |
| `binary` | ✅ Доступен | Генерация бинарных данных |
| `cocos` | ✅ Доступен | Генерация кода для платформы Cocos |
| `typescript` | ✅ Доступен | Генерация кода TypeScript |
| `dejavu` | ✅ Доступен | Генерация кода через шаблонизатор |
| `unity` | ⚠️ Отключён | Генерация кода для платформы Unity (в процессе рефакторинга) |
| `xlua` | В разработке | Генерация скриптов XLua |
| `sql` | В разработке | Генерация кода для базы данных SQL |
| `xml` | В разработке | Генерация данных XML |

## Кроссплатформенная поддержка

XCell разработан как кроссплатформенный инструмент, поддерживающий совместное использование конфигурационных данных между различными платформами, обеспечивая согласованность данных и эффективность разработки.

### Кроссплатформенный обмен данными

- Унифицированная модель данных
- Кроссплатформенный маппинг типов
- Стандартизированный формат конфигурации

### Лучшие практики

- Выбирайте подходящий формат данных в зависимости от целевой платформы
- Используйте правила слияния для управления кроссплатформенными данными
- Регулярно синхронизируйте структуры данных между платформами
