# Мета-атрибуты

Мета-атрибуты используются для добавления дополнительной конфигурационной информации к полям, такой как правила валидации, значения по умолчанию и т.д.

## Базовый формат

Мета-атрибуты начинаются с `@` и могут быть написаны в трёх позициях:

| Позиция | Пример |
| -------- | ------- |
| После имени поля | `id @primary` |
| После типа | `i32 @min(1)` |
| В комментарии Excel | `@default(100)` |

> **Рекомендация**: Мета-атрибутов может быть любое количество, рекомендуется писать их единообразно в комментариях ячеек Excel для удобства управления и сопровождения.

## Часто используемые мета-атрибуты

### Мета-атрибуты полей

| Мета-атрибут | Описание | Пример |
| -------------- | ----------- | ------- |
| `@primary` | Первичный ключ | `id @primary` |
| `@default(value)` | Значение по умолчанию | `level @default(1)` |
| `@virtual` | Виртуальное поле | `user @virtual` |

### Мета-атрибуты типов

| Мета-атрибут | Описание | Пример |
| -------------- | ----------- | ------- |
| `@min(value)` | Минимальное значение | `i32 @min(0)` |
| `@max(value)` | Максимальное значение | `i32 @max(100)` |
| `@range(min, max)` | Диапазон | `i32 @range(1, 100)` |

### Мета-атрибуты в комментариях

Мета-атрибуты можно писать в комментариях ячеек Excel:

```
@default(100)
@min(1)
@max(9999)
```

## Виртуальные поля

Виртуальные поля — это специальные поля, которые не хранят фактические данные, а получают значения путём ссылки на данные из других таблиц.

### Пример

| @dict | Name | Quality ID | Quality |
| ----- | ---- | ---------- | ------- |
| item_id | name | quality_id | quality @virtual |
| string | string | &Quality | Quality |
| sword_001 | Железный меч | common | |
| sword_002 | Стальной меч | rare | |

- `quality_id` — фактически хранимое поле, тип `&Quality`
- `quality` — виртуальное поле, помеченное `@virtual`, тип — имя целевой таблицы `Quality`

## Вычисляемые свойства

Вычисляемые свойства — это поля, получаемые через вычисление выражений, не требующие хранения фактических данных.

### Пример

| @dict | Base Attack | Enhance Level | Total Attack |
| ----- | ----------- | ------------- | ------------ |
| item_id | base_atk | enhance | total_atk @computed |
| string | i32 | i32 | i32 |
| sword_001 | 100 | 5 | base_atk * (1 + enhance * 0.1) |

- `total_atk` — вычисляемое свойство, помеченное `@computed`
- Выражения могут ссылаться на другие поля в той же таблице

## Мета-атрибуты и генерация кода

Мета-атрибуты влияют на сгенерированный код:

### Атрибуты валидации

```
level i32 @range(1, 100)
```

Сгенерированный код C#:

```csharp
[Range(1, 100)]
public int Level { get; set; }
```

### Значение по умолчанию

```
quality string @default(common)
```

Сгенерированный код C#:

```csharp
public string Quality { get; set; } = "common";
```

## Примечания

- Мета-атрибуты начинаются с `@`
- Могут быть написаны в имени поля, типе или комментарии Excel
- Несколько мета-атрибутов можно комбинировать
- Некоторые мета-атрибуты влияют на генерацию кода и валидацию данных
