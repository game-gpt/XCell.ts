## Поддержка нескольких движков

Философия дизайна XCell — предоставлять отличные решения для управления конфигурационными таблицами для всех игровых движков:

- **Unity (C#)**: Полная встроенная поддержка
- **Cocos Creator**: Через загрузчики JSON/XML + TypeScript/Lua
- **Godot**: Через загрузчики JSON + GDScript
- **Unreal Engine**: Через загрузчики бинарных данных + C++
- **Пользовательские движки**: Создание пользовательских экспортёров через документацию по расширяемости

## Предварительные требования

Перед чтением этого раздела рекомендуется:

1. Быть знакомым с базовым использованием XCell
2. Понимать базовую структуру файла конфигурации проекта `XCell.toml`
3. Иметь базовые навыки программирования на целевых языках (Rust, C#, C++, Python, Lua, TypeScript и др.)
