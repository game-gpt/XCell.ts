# Система типов

XCell поддерживает множество типов данных. Стандартные типы следуют соглашениям Rust, при этом обеспечивая совместимость с соглашениями C и C++. Типы нечувствительны к регистру.

## Базовые типы

### Целые типы

| Стандартная нотация | Соглашение Unity | Соглашение Unreal | Описание | Диапазон |
| ----------------- | ---------------- | ----------------- | ----------- | ----- |
| `i8` | `char` | `int8_t` | 8-битное знаковое целое | -128 до 127 |
| `u8` | `unsigned char` | `uint8_t` | 8-битное беззнаковое целое | 0 до 255 |
| `i16` | `short` | `int16_t` | 16-битное знаковое целое | -32768 до 32767 |
| `u16` | `unsigned short` | `uint16_t` | 16-битное беззнаковое целое | 0 до 65535 |
| `i32` | `int` | `int32_t` | 32-битное знаковое целое | -2147483648 до 2147483647 |
| `u32` | `unsigned int` | `uint32_t` | 32-битное беззнаковое целое | 0 до 4294967295 |
| `i64` | `long long` | `int64_t` | 64-битное знаковое целое | -9223372036854775808 до 9223372036854775807 |
| `u64` | `unsigned long long` | `uint64_t` | 64-битное беззнаковое целое | 0 до 18446744073709551615 |

## Составные типы

### Типы массивов и векторов

**Различные соглашения о типах**:

| Стандартная нотация | Соглашение C# | Описание |
| ----------------- | ------------- | ----------- |
| `[T]` | `T[]` | Динамический массив |
| `[T; N]` | `T[N]` | Статический массив (фиксированный размер) |
| `Vec<T>` | `List<T>` | Тип вектора/списка |
| `vec2<f32>` | `Vector2<float>` | 2D-вектор |
| `vec3<f32>` | `Vector3<float>` | 3D-вектор |
| `vec4<f32>` | `Vector4<float>` | 4D-вектор |

**Описание**:

- Динамический массив `[T]` и вектор `Vec<T>` используются для хранения переменного количества элементов
- Статический массив `[T; N]` используется для хранения фиксированного количества элементов, длина определяется при определении
- Специальные векторные типы (vec2/vec3/vec4) часто используются в графическом программировании, Unity и другие движки имеют специфические оптимизации производительности

**Примеры**:

- `[i32; 5]` - Статический массив, содержащий 5 элементов i32
- `[string]` - Динамический массив строк
- `Vec<i32>` - Целочисленный вектор
- `vec3<f32>` - 3D-вектор чисел с плавающей точкой

### Тип словаря

**Формат**: `HashMap<K, V>` или `dict<K, V>`

**Примеры**:

- `HashMap<string, i32>` - Отображение строки в целое число
- `dict<i32, string>` - Отображение целого числа в строку

### Тип кортежа

**Формат**: `(T1, T2, ...)`

**Примеры**:

- `(i32, string)` - Кортеж, содержащий целое число и строку
- `(f32, f32, bool)` - Кортеж, содержащий два числа с плавающей точкой и одно логическое значение

## Уникальный тип и первичный ключ

**Формат уникального типа**:

- `@T` - Указывает, что значение поля должно быть уникальным в таблице, т.е. никакие две строки в таблице не могут иметь одинаковое значение этого поля
- `@@T` - Указывает, что значение поля должно быть уникальным в таблице и является первичным ключом

**Описание первичного ключа**:

- Первичный ключ — это поле, используемое для уникальной идентификации каждой строки данных в таблице
- Если в таблице не используется `@@T` для явной маркировки первичного ключа, первый столбец таблицы автоматически считается первичным ключом
- Значения первичного ключа должны быть уникальными и не могут быть null, используются для установления связей между таблицами

**Примеры**:

- `@@i32` - Целочисленное поле первичного ключа
- `@string` - Строковое уникальное поле (не первичный ключ)

## Пользовательские типы

### Типы перечислений

Типы перечислений, определённые через таблицы Enumerate, могут использоваться в других таблицах.

**Пример**:

- `QualityType` - Ссылается на тип качества, определённый в таблице enum

### Типы структур

Типы структур, определённые через таблицы Class, могут использоваться в других таблицах.

**Пример**:

- `Position` - Ссылается на структуру позиции, определённую в таблице Class

## Преобразование типов

XCell поддерживает автоматическое преобразование типов, например:

- Целые числа могут быть автоматически преобразованы в числа с плавающей точкой
- Числа с плавающей точкой могут быть преобразованы в целые числа при необходимости (десятичная часть будет отброшена)
- Числа могут быть преобразованы в строки
- Строки могут быть преобразованы в числа в подходящих случаях

## Валидация типов

XCell выполняет валидацию типов при разборе таблиц, обеспечивая соответствие данных указанным требованиям типов. Если типы не совпадают, ошибки будут сгенерированы во время компиляции.
