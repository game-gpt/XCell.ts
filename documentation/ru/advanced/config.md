# Файлы конфигурации

XCell использует файлы конфигурации в формате TOML для управления настройками проекта. Файл конфигурации называется `XCell.toml` и расположен в корневой директории проекта.

## Базовая конфигурация

| Параметр конфигурации | Тип | Описание | Значение по умолчанию |
|--------------------|------|-------------|---------------|
| version | string | Номер версии файла конфигурации | "0.0.0" |
| include | string | Шаблон пути к файлам Excel для включения (наивысший приоритет) | "*.xlsx" |
| exclude | string | Шаблон пути к файлам Excel для исключения (приоритет ниже, чем у include) | "" |

### Конфигурация строк (line)

Определяет номера строк, где расположена различная информация в таблице (начиная с 1).

| Параметр конфигурации | Тип | Описание | Значение по умолчанию |
|--------------------|------|-------------|---------------|
| line.field | int | Строка, где расположены имена полей | 1 |
| line.type | int | Строка, где расположены типы данных | 2 |
| line.comment | int | Строка, где расположены комментарии | 3 |
| line.data | int | Строка, с которой начинаются данные | 4 |

#### Миграция устаревших таблиц

Формат таблицы XCell по умолчанию:

| Номер строки | Содержимое |
|------------|---------|
| Строка 1 | Комментарии к полям |
| Строка 2 | Имена полей |
| Строка 3 | Типы полей |
| Строка 4+ | Строки данных |

Если формат вашей устаревшей таблицы отличается, вы можете настроить его через маппинг строк. Например, если формат устаревшей таблицы:

| Номер строки | Содержимое |
|------------|---------|
| Строка 1 | Имена полей |
| Строка 2 | Типы полей |
| Строка 3+ | Строки данных |

Настройте следующим образом:

```toml
line.field = 1
line.type = 2
line.comment = 0  # Нет строки комментариев
line.data = 3
```

> Примечание: `line.comment = 0` означает отсутствие строки комментариев.

### Конфигурация разбора типов (type)

Настройте правила разбора для различных типов данных.

#### Логический тип (bool)

| Параметр конфигурации | Тип | Описание |
|--------------------|------|-------------|
| type.bool.accept | array[string] | Список значений, принимаемых как true |
| type.bool.reject | array[string] | Список значений, принимаемых как false |

Пример:
```toml
[type.bool]
accept = ["true", "√", "是", "1"]
reject = ["false", "x", "否", "0"]
```

### Конфигурация генерации кода Unity (unity)

Настройте параметры генерации кода C#.

| Параметр конфигурации | Тип | Описание | Значение по умолчанию |
|--------------------|------|-------------|---------------|
| unity.enable | bool | Включить ли генерацию кода Unity | true |
| unity.project | string | Путь к проекту Unity | "../" |
| unity.output | string | Директория вывода кода | "Assets/Scripts/DataTable/Generated" |
| unity.namespace | string | Пространство имён сгенерированного кода | "DataTable.Generated" |
| unity.manager | string | Имя класса менеджера | "DataTableManager" |
| unity.suffix_table | string | Суффикс класса таблицы | "Table" |
| unity.suffix_element | string | Суффикс класса элемента | "Element" |
| unity.support_clone | bool | Поддерживать ли клонирование | true |
| unity.legacy_using | bool | Использовать ли устаревший using | false |
| unity.legacy_null_null | bool | Использовать ли устаревшую обработку null | false |

### Конфигурация формата вывода данных

Настройте вывод файлов данных в различных форматах.

#### Бинарный формат

| Параметр конфигурации | Тип | Описание | Значение по умолчанию |
|--------------------|------|-------------|---------------|
| unity.binary.enable | bool | Включить ли вывод в бинарном формате | true |
| unity.binary.output | string | Директория вывода бинарных файлов | "Assets/Tables/Generated" |

#### Формат XML

| Параметр конфигурации | Тип | Описание | Значение по умолчанию |
|--------------------|------|-------------|---------------|
| unity.xml.enable | bool | Включить ли вывод в формате XML | false |
| unity.xml.output | string | Директория вывода XML файлов | "Assets/Tables/Readable" |

#### Формат JSON

| Параметр конфигурации | Тип | Описание | Значение по умолчанию |
|--------------------|------|-------------|---------------|
| unity.json.enable | bool | Включить ли вывод в формате JSON | false |
| unity.json.output | string | Директория вывода JSON файлов | "Assets/Tables/Readable" |

#### Другие форматы

- **xlua**: Генерация кода Lua
- **protobuf**: Вывод в формате Protobuf

## Инструкция по использованию

1. Создайте файл `XCell.toml` в корневой директории проекта
2. Измените параметры конфигурации по необходимости
3. Инструмент XCell автоматически загрузит конфигурацию при запуске
4. Конфигурация таблицы может переопределять глобальную конфигурацию (создайте файл `.toml` с тем же именем)
