# 테이블 병합 규칙

XCell은 여러 테이블을 하나의 테이블로 병합하는 것을 지원합니다. 병합 규칙을 통해 복잡한 데이터 구조를 유연하게 관리할 수 있습니다.

## 명명 규칙

- **PascalCase 명명** (예: `ItemWeapon`, `ItemArmor`): 독립적인 테이블, 병합에 참여하지 않음
- **밑줄 명명** (예: `Item_Weapon`, `Item_Armor`): 자동으로 `Item` 테이블로 병합

## 예제

| 파일 이름 | 동작 |
| ---------- | ---- |
| `ItemWeapon.xlsx` | 독립 테이블, `ItemWeapon` 생성 |
| `ItemArmor.xlsx` | 독립 테이블, `ItemArmor` 생성 |
| `Item_Weapon.xlsx` | `Item`으로 병합 |
| `Item_Armor.xlsx` | `Item`으로 병합 |
| `Item_Consumable.xlsx` | `Item`으로 병합 |

## 병합 로직

- 동일한 구조의 테이블이 병합됩니다
- **중복 ID는 오류를 발생시킵니다** (병합 순서는 디스크 저장에 따라 결정되며, 고정되지 않습니다)
- 최종 출력은 ID 기준으로 정렬됩니다

## 사용 사례

### 시나리오: 유형별 테이블 관리

다음과 같은 아이템 테이블이 있다고 가정합니다:
- `Item_Weapon.xlsx` - 무기 설정
- `Item_Armor.xlsx` - 방어구 설정
- `Item_Consumable.xlsx` - 소모품 설정

이들은 자동으로 `Item` 테이블로 병합됩니다.

## 주의 사항

- 병합되는 테이블은 동일한 구조(동일한 열 이름과 타입)를 가져야 합니다
- 기본 키가 충돌하면 나중에 병합된 파일의 데이터가 이전에 병합된 파일의 데이터를 덮어씁니다
- 병합 작업을 수행하기 전에 원본 파일을 백업하는 것이 좋습니다
- **`Language`는 예약된 테이블 이름입니다**, 모든 언어 테이블은 Language로 병합되므로 이 이름을 사용하지 마세요
