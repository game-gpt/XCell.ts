# XCell 기능

## 테이블 유형

| 유형 | 설명 |
| ---- | ---- |
| dict 테이블 | 문자열 기본 키, 가장 일반적인 설정 양식 |
| list 테이블 | 정수 기본 키, 순차적 접근 |
| enum 테이블 | 추가 데이터가 첨부된 열거형 타입 |
| class 테이블 | 전역 설정 클래스, 싱글톤 패턴 |
| language 테이블 | 다국어 지원 |

## 코드 생성 대상

| 대상 | 언어/형식 | 상태 |
| ---- | --------- | ---- |
| Unity | C# | ✅ 구현됨 |
| Cocos | TypeScript + JSON | ✅ 구현됨 |
| JSON | JSON 데이터 | ✅ 구현됨 |
| Binary | 바이너리 데이터 | ✅ 구현됨 |
| Dejavu | 템플릿 엔진 | ✅ 구현됨 |

## 타입 시스템

### 기본 타입

| 타입 | 설명 |
| ---- | ---- |
| `bool` | 불리언 값 |
| `i8`, `i16`, `i32`, `i64` | 부호 있는 정수 |
| `u8`, `u16`, `u32`, `u64` | 부호 없는 정수 |
| `f32`, `f64` | 부동소수점 수 |
| `string` | 문자열 |

### 복합 타입

| 타입 | 설명 |
| ---- | ---- |
| `[T]` | 동적 배열 |
| `[T; N]` | 정적 배열 |
| `Vec<T>` | 벡터/리스트 |
| `vec2`, `vec3`, `vec4` | 벡터 타입 |
| `HashMap<K, V>` | 딕셔너리 타입 |

### 특수 타입

| 타입 | 설명 |
| ---- | ---- |
| `color` | 색상 타입 |
| `datetime`, `time`, `date` | 시간 타입 |
| `&T` | 참조 타입 |

## 테이블 병합 기능

- **명명 규칙**: 밑줄 명명은 자동 병합, 예: `Item_Weapon` + `Item_Armor` → `Item`
- **병합 규칙**: 동일한 구조는 자동 병합, 중복 ID는 오류 발생
- **예약된 테이블 이름**: `Language`는 예약된 테이블 이름입니다

## 설정 시스템

- **프로젝트 설정**: 프로젝트 루트의 `XCell.toml`
- **테이블 설정**: 동일한 이름의 `.toml` 파일
- **행 매핑**: 레거시 테이블 마이그레이션 지원

## 아키텍처

```
xcell-provider (테이블 읽기/쓰기)
    ↓
xcell-analyzer (테이블 분석)
    ↓
xcell-generator (코드 생성)
    ↓
xcell (CLI 도구)
```

## 핵심 모듈

| 모듈 | 기능 |
| ---- | ---- |
| xcell-types | 타입 시스템 정의 |
| xcell-provider | 테이블 읽기/쓰기 인터페이스 |
| xcell-parser | 구문 파서 |
| xcell-analyzer | 테이블 분석기 |
| xcell-config | 설정 관리 |
| xcell-generator | 코드 생성기 |
| xcell-plugin | 플러그인 시스템 |
| xcell | 명령줄 도구 |
