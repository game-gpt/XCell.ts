# 사용 사례

이 페이지는 다양한 시나리오에서 XCell의 사용 예제와 모범 사례를 포함합니다.

## 사용 가능한 사례

- [Unity 통합](unity-integration.md) - XCell과 Unity 게임 엔진 통합

## 사례 설명

### Unity 통합

Unity 엔진을 사용하여 게임을 개발하는 개발자에게 적합합니다. 이 사례는 XCell 설정 테이블 관리 도구를 Unity 프로젝트와 원활하게 통합하는 방법을 자세히 설명하며, 다음을 포함합니다:

- Unity 프로젝트 설정
- 설정 테이블 생성 및 관리
- C# 코드 생성
- 바이너리 데이터 로딩
- 런타임 사용 예제
