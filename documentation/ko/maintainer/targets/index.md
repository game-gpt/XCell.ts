# 대상 플랫폼

XCell은 프론트엔드와 백엔드를 포함한 여러 대상 플랫폼을 지원합니다. 이 장에서는 각 플랫폼의 통합 방법과 타입 매핑을 자세히 설명합니다.

## 프론트엔드 플랫폼

프론트엔드 플랫폼은 주로 게임 엔진과 프론트엔드 프레임워크를 대상으로 하며, 코드 생성 및 데이터 로딩 기능을 제공합니다.

### 게임 엔진

- [Unity](unity.md) - Unity 엔진 통합 ⚠️ (현재 비활성화)
- [Cocos](cocos.md) - Cocos 엔진 통합 ✅
- [Unreal Engine](unreal.md) - 언리얼 엔진 통합
- [Godot](godot.md) - Godot 엔진 통합
- [XLua](xlua.md) - XLua 스크립트 통합

### 프론트엔드 프레임워크

- [React](react.md) - React 프레임워크 통합
- [Vue](vue.md) - Vue 프레임워크 통합
- [TypeScript/JavaScript](typescript.md) - TypeScript/JavaScript 통합 ✅

## 백엔드 플랫폼

백엔드 플랫폼은 주로 서버 측 및 데이터 저장소를 대상으로 하며, 데이터 지속성 및 서버 측 통합을 제공합니다.

### 데이터 형식

- [JSON](json.md) - JSON 데이터 형식 ✅
- [SQL](sql.md) - SQL 데이터베이스 통합

## 코드 생성기 상태 설명

| 생성기 | 상태 | 설명 |
| ------- | ---- | ---- |
| `json` | ✅ 사용 가능 | JSON 데이터 생성 |
| `binary` | ✅ 사용 가능 | 바이너리 데이터 생성 |
| `cocos` | ✅ 사용 가능 | Cocos 플랫폼 코드 생성 |
| `typescript` | ✅ 사용 가능 | TypeScript 코드 생성 |
| `dejavu` | ✅ 사용 가능 | 템플릿 엔진 코드 생성 |
| `unity` | ⚠️ 비활성화 | Unity 플랫폼 코드 생성 (리팩토링 중) |
| `xlua` | 개발 중 | XLua 스크립트 코드 생성 |
| `sql` | 개발 중 | SQL 데이터베이스 코드 생성 |
| `xml` | 개발 중 | XML 데이터 생성 |

## 크로스 플랫폼 지원

XCell은 크로스 플랫폼으로 설계되어 다양한 플랫폼 간에 설정 데이터를 공유할 수 있으며, 데이터 일관성과 개발 효율성을 보장합니다.

### 크로스 플랫폼 데이터 공유

- 통일된 데이터 모델
- 크로스 플랫폼 타입 매핑
- 표준화된 설정 형식

### 모범 사례

- 대상 플랫폼에 따라 적절한 데이터 형식 선택
- 병합 규칙을 사용하여 크로스 플랫폼 데이터 관리
- 플랫폼 간의 데이터 구조를 정기적으로 동기화
