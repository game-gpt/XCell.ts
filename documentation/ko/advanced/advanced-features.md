## 고급 설정 옵션

XCell의 설정 파일 `XCell.toml`은 풍부한 설정 옵션을 제공하여 도구의 동작을 유연하게 사용자 정의할 수 있습니다.

### 기본 설정 구조

완전한 `XCell.toml` 설정 파일은 다음과 같은 주요 부분을 포함합니다:

```toml
version = "0.0.0"

exclude = ""
include = "*.xlsx"

line.field = 1
line.type = 2
line.comment = 3
line.data = 4

[type.bool]
accept = ["true", "√"]
reject = ["false", "x"]

[type.string]

[merge]
```

### 버전 관리 설정

```toml
version = "0.0.0"
```

- **version**: 현재 프로젝트 버전 번호, 생성된 코드와 데이터 파일의 버전을 식별하는 데 사용

### 파일 포함/제외 설정

```toml
exclude = ""
include = "*.xlsx"
```

- **include**: 포함할 Excel 파일 패턴, 와일드카드 지원
- **exclude**: 제외할 Excel 파일 패턴, include보다 우선순위가 낮음

예제:
```toml
include = "tables/**/*.xlsx"
exclude = "tables/temp/*.xlsx"
```

### 테이블 행 설정

```toml
line.field = 1
line.type = 2
line.comment = 3
line.data = 4
```

- **line.field**: 필드 이름이 위치한 행 번호 (1부터 시작)
- **line.type**: 타입 선언이 위치한 행 번호
- **line.comment**: 주석이 위치한 행 번호
- **line.data**: 데이터가 시작되는 행 번호

### 타입 설정

#### 불리언 타입 설정

```toml
[type.bool]
accept = ["true", "√"]
reject = ["false", "x"]
```

- **accept**: true로 인식되는 값 목록
- **reject**: false로 인식되는 값 목록

#### 문자열 타입 설정

```toml
[type.string]
# 확장 가능한 설정
```

## 테이블 병합 규칙 상세

테이블 병합 규칙을 사용하면 여러 Excel 테이블을 하나로 병합할 수 있으며, 행 또는 열 병합을 지원합니다.

### 병합 규칙 설정

병합 규칙은 `[merge]` 섹션에서 설정하며, 각 규칙은 고유한 번호를 식별자로 사용합니다.

```toml
[merge.10001]
mode = "row"
input = "Language_CN*"
target = "Language_CN"

[merge.10002]
mode = "row"
input = "Language_EN*"
target = "Language_EN"

[merge.20001]
mode = "column"
input = "Language*"
target = "Language"
```

### 병합 모드

#### 행 병합 모드 (row)

```toml
mode = "row"
```

행 병합은 여러 테이블의 데이터 행을 하나의 테이블로 결합합니다. 다음에 적합합니다:
- 관리를 위해 분할해야 하는 대용량 테이블
- 다국어 데이터 분리 관리

예제 디렉토리 구조:
```
LanguageTable/
  - CN/
    - Language_CN_UI.xlsx
    - Language_CN_Item.xlsx
  - EN/
    - Language_EN_UI.xlsx
    - Language_EN_Item.xlsx
```

#### 열 병합 모드 (column)

```toml
mode = "column"
```

열 병합은 여러 테이블의 열을 하나의 테이블로 결합합니다. 다음에 적합합니다:
- 열 데이터를 다른 파일에 분산
- 다른 팀이 동일한 테이블의 다른 부분을 협업

### 병합 규칙 매개변수

- **mode**: 병합 모드, `row` 또는 `column`
- **input**: 입력 파일 패턴, 와일드카드 지원
- **target**: 대상 테이블 이름

### 병합 실행 순서

규칙 번호는 병합의 실행 순서를 결정하며, 번호가 작을수록 먼저 실행됩니다. 권장 사항:
- 행 병합은 10000-19999 범위 사용
- 열 병합은 20000-29999 범위 사용
- 다른 사용자 정의 규칙은 더 높은 번호 사용

## 성능 최적화 팁

### 대용량 테이블 처리 최적화

#### 1. 대용량 테이블 합리적 분할

- 기능이나 모듈별로 대용량 테이블 분할
- 행 병합 규칙을 사용하여 빌드 시 병합
- 개발 시 유지보수성과 런타임 성능 유지

#### 2. 바이너리 형식 사용

- 바이너리 형식이 가장 빠른 로딩 속도를 제공
- 프로덕션 환경에서는 바이너리 형식 권장
- 개발 환경에서는 디버깅을 위해 XML/JSON 사용 가능

### 증분 업데이트 최적화

#### 1. 감시 모드

감시 모드 사용:

```bash
xcell.exe --watch
```

감시 모드 기능:
- 변경된 파일만 재생성
- 개발 효율성 크게 향상
- 실시간 미리보기 지원

#### 2. 합리적인 감시 설정

합리적인 include/exclude 패턴을 설정하여 감시할 파일 수를 줄입니다.

### 메모리 최적화

#### 1. 필요한 테이블만 로드

다양한 엔진 API에 따라 현재 장면이나 기능에 필요한 테이블만 로드하고, 모든 테이블을 한 번에 로드하는 것을 피합니다.

#### 2. 적시에 언로드

특정 테이블이 더 이상 필요하지 않을 때 적시에 언로드하여 메모리를 해제합니다.

### 빌드 최적화

#### 1. 병렬 처리

XCell은 여러 파일의 병렬 처리를 지원하여 빌드 속도를 크게 향상시킵니다.

#### 2. 캐싱 메커니즘

합리적으로 캐시를 사용하여 반복 처리를 방지합니다.
