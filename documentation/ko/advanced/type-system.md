# 타입 시스템

XCell은 여러 데이터 타입을 지원합니다. 표준 타입은 Rust 규칙을 따르며, C 규칙 및 C++ 규칙과도 호환됩니다. 타입은 대소문자를 구분하지 않습니다.

## 기본 타입

### 정수 타입

| 표준 표기 | Unity 규칙 | Unreal 규칙 | 설명 | 범위 |
| --------- | ---------- | ----------- | ---- | ---- |
| `i8` | `char` | `int8_t` | 8비트 부호 있는 정수 | -128 ~ 127 |
| `u8` | `unsigned char` | `uint8_t` | 8비트 부호 없는 정수 | 0 ~ 255 |
| `i16` | `short` | `int16_t` | 16비트 부호 있는 정수 | -32768 ~ 32767 |
| `u16` | `unsigned short` | `uint16_t` | 16비트 부호 없는 정수 | 0 ~ 65535 |
| `i32` | `int` | `int32_t` | 32비트 부호 있는 정수 | -2147483648 ~ 2147483647 |
| `u32` | `unsigned int` | `uint32_t` | 32비트 부호 없는 정수 | 0 ~ 4294967295 |
| `i64` | `long long` | `int64_t` | 64비트 부호 있는 정수 | -9223372036854775808 ~ 9223372036854775807 |
| `u64` | `unsigned long long` | `uint64_t` | 64비트 부호 없는 정수 | 0 ~ 18446744073709551615 |

## 복합 타입

### 배열 및 벡터 타입

**다른 타입 규칙**:

| 표준 표기 | C# 규칙 | 설명 |
| --------- | ------- | ---- |
| `[T]` | `T[]` | 동적 배열 |
| `[T; N]` | `T[N]` | 정적 배열 (고정 크기) |
| `Vec<T>` | `List<T>` | 벡터/리스트 타입 |
| `vec2<f32>` | `Vector2<float>` | 2D 벡터 |
| `vec3<f32>` | `Vector3<float>` | 3D 벡터 |
| `vec4<f32>` | `Vector4<float>` | 4D 벡터 |

**설명**:

- 동적 배열 `[T]`과 벡터 `Vec<T>`은 가변 개수의 요소를 저장하는 데 사용됩니다
- 정적 배열 `[T; N]`은 고정 개수의 요소를 저장하는 데 사용되며, 길이는 정의 시 결정됩니다
- 특수 벡터 타입(vec2/vec3/vec4)은 그래픽 프로그래밍에서 자주 사용되며, Unity 및 기타 엔진에 특정 성능 최적화가 있습니다

**예제**:

- `[i32; 5]` - 5개의 i32 요소를 포함하는 정적 배열
- `[string]` - 동적 크기의 문자열 배열
- `Vec<i32>` - 정수 벡터
- `vec3<f32>` - 3D 부동소수점 벡터

### 딕셔너리 타입

**형식**: `HashMap<K, V>` 또는 `dict<K, V>`

**예제**:

- `HashMap<string, i32>` - 문자열에서 정수로의 매핑
- `dict<i32, string>` - 정수에서 문자열로의 매핑

### 튜플 타입

**형식**: `(T1, T2, ...)`

**예제**:

- `(i32, string)` - 정수와 문자열을 포함하는 튜플
- `(f32, f32, bool)` - 두 개의 부동소수점 수와 하나의 불리언을 포함하는 튜플

## 고유 타입과 기본 키

**고유 타입 형식**:

- `@T` - 필드 값이 테이블 내에서 고유해야 함을 나타냄. 즉, 테이블의 두 행이 이 필드에 대해 같은 값을 가질 수 없음
- `@@T` - 필드 값이 테이블 내에서 고유해야 하며 기본 키로 사용됨을 나타냄

**기본 키 설명**:

- 기본 키는 테이블의 각 데이터 행을 고유하게 식별하는 데 사용되는 필드입니다
- 테이블에서 `@@T`를 사용하여 기본 키를 명시적으로 표시하지 않은 경우, 테이블의 첫 번째 열이 자동으로 기본 키로 처리됩니다
- 기본 키 값은 고유하고 null이 아니어야 하며, 테이블 간의 연관을 설정하는 데 사용됩니다

**예제**:

- `@@i32` - 정수 타입 기본 키 필드
- `@string` - 문자열 타입 고유 필드 (기본 키 아님)

## 사용자 정의 타입

### 열거형 타입

Enum 테이블을 통해 정의된 열거형 타입은 다른 테이블에서 사용할 수 있습니다.

**예제**:

- `QualityType` - enum 테이블에 정의된 품질 타입 참조

### 구조체 타입

Class 테이블을 통해 정의된 구조체 타입은 다른 테이블에서 사용할 수 있습니다.

**예제**:

- `Position` - Class 테이블에 정의된 위치 구조체 참조

## 타입 변환

XCell은 자동 타입 변환을 지원합니다. 예:

- 정수는 부동소수점 수로 자동 변환될 수 있습니다
- 부동소수점 수는 필요한 경우 정수로 변환될 수 있습니다 (소수 부분이 잘림)
- 숫자는 문자열로 변환될 수 있습니다
- 문자열은 적절한 경우 숫자로 변환될 수 있습니다

## 타입 검증

XCell은 테이블을 파싱할 때 타입 검증을 수행하여 데이터가 지정된 타입 요구 사항을 준수하는지 확인합니다. 타입이 일치하지 않으면 컴파일 시간에 오류가 생성됩니다.
