# XCell 機能特性

## 表タイプ

| タイプ | 説明 |
| ---- | ---- |
| dict 表 | 文字列主キー、最も一般的な設定形式 |
| list 表 | 整数主キー、順次アクセス |
| enum 表 | 列挙型、追加データ付き |
| class 表 | グローバル設定クラス、シングルトンパターン |
| language 表 | 多言語サポート |

## コード生成ターゲット

| ターゲット | 言語/フォーマット | 状態 |
| ---- | --------- | ---- |
| Unity | C# | ✅ 実装済み |
| Cocos | TypeScript + JSON | ✅ 実装済み |
| JSON | JSON データ | ✅ 実装済み |
| Binary | バイナリデータ | ✅ 実装済み |
| Dejavu | テンプレートエンジン | ✅ 実装済み |

## 型システム

### 基本型

| 型 | 説明 |
| ---- | ---- |
| `bool` | ブール値 |
| `i8`, `i16`, `i32`, `i64` | 符号付き整数 |
| `u8`, `u16`, `u32`, `u64` | 符号なし整数 |
| `f32`, `f64` | 浮動小数点数 |
| `string` | 文字列 |

### 複合型

| 型 | 説明 |
| ---- | ---- |
| `[T]` | 動的配列 |
| `[T; N]` | 静的配列 |
| `Vec<T>` | ベクター/リスト |
| `vec2`, `vec3`, `vec4` | ベクトル型 |
| `HashMap<K, V>` | 辞書型 |

### 特殊型

| 型 | 説明 |
| ---- | ---- |
| `color` | カラー型 |
| `datetime`, `time`, `date` | 時間型 |
| `&T` | 参照型 |

## 表結合機能

- **命名規則**：アンダースコア命名で自動結合、例：`Item_Weapon` + `Item_Armor` → `Item`
- **結合ルール**：同じ構造は自動結合、同じ ID はエラー
- **予約テーブル名**：`Language` は予約テーブル名

## 設定システム

- **プロジェクト設定**：`XCell.toml` プロジェクトルートディレクトリ
- **テーブル設定**：同名の `.toml` ファイル
- **行マッピング**：旧テーブルの移行をサポート

## アーキテクチャ

```
xcell-provider (テーブル読み書き)
    ↓
xcell-analyzer (テーブル分析)
    ↓
xcell-generator (コード生成)
    ↓
xcell (CLI ツール)
```
