# 表結合ルール

XCell は複数の表を1つの表に結合する機能をサポートしており、表結合ルールによって複雑なデータ構造を柔軟に管理できます。

## 命名規則

- **アッパーキャメルケース**（例：`ItemWeapon`、`ItemArmor`）：独立した表、結合に参加しない
- **アンダースコア命名**（例：`Item_Weapon`、`Item_Armor`）：自動的に `Item` 表に結合

## 例

| ファイル名 | 動作 |
|--------|------|
| `ItemWeapon.xlsx` | 独立した表、`ItemWeapon` を生成 |
| `ItemArmor.xlsx` | 独立した表、`ItemArmor` を生成 |
| `Item_Weapon.xlsx` | `Item` に結合 |
| `Item_Armor.xlsx` | `Item` に結合 |
| `Item_Consumable.xlsx` | `Item` に結合 |

## 結合ロジック

- 同じ構造を持つ表が結合されます
- **同じ ID があるとエラー**（結合順序はディスクの格納方法に関連し、固定ではありません）
- 最終産物は ID でソートされます

## 使用シナリオ

### シナリオ：タイプ別に表を分割管理

以下のアイテム表があるとします：
- `Item_Weapon.xlsx` - 武器設定
- `Item_Armor.xlsx` - 防具設定
- `Item_Consumable.xlsx` - 消耗品設定

これらは自動的に `Item` 表に結合されます。

## 注意事項

- 結合される表は同じ構造（同じ列名と型）を持つ必要があります
- 主キーが競合する場合、後に結合されるファイルのデータが先に結合されたファイルのデータを上書きします
- 表結合操作を行う前に元のファイルをバックアップすることを推奨します
- **`Language` は予約テーブル名**、すべての言語表は Language に結合されるため、この名前は使用しないでください
