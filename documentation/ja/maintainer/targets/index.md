# Targets ターゲットプラットフォーム

XCell は複数のターゲットプラットフォームをサポートし、フロントエンドとバックエンドが含まれます。この章では、各プラットフォームの統合方法と型マッピングについて詳しく説明します。

## フロントエンドプラットフォーム

フロントエンドプラットフォームは主にゲームエンジンとフロントエンドフレームワークを対象とし、コード生成とデータ読み込み機能を提供します。

### ゲームエンジン

- [Unity](unity.md) - Unity エンジン統合 ⚠️ (現在無効)
- [Cocos](cocos.md) - Cocos エンジン統合 ✅
- [Unreal Engine](unreal.md) - Unreal Engine 統合
- [Godot](godot.md) - Godot エンジン統合
- [XLua](xlua.md) - XLua スクリプト統合

### フロントエンドフレームワーク

- [React](react.md) - React フレームワーク統合
- [Vue](vue.md) - Vue フレームワーク統合
- [TypeScript/JavaScript](typescript.md) - TypeScript/JavaScript 統合 ✅

## バックエンドプラットフォーム

バックエンドプラットフォームは主にサーバーサイドとデータストレージを対象とし、データ永続化とサーバーサイド統合を提供します。

### データフォーマット

- [JSON](json.md) - JSON データフォーマット ✅
- [SQL](sql.md) - SQL データベース統合

## コードジェネレーターの状態説明

| ジェネレーター | 状態 | 説明 |
|--------|------|------|
| `json` | ✅ 利用可能 | JSON データ生成 |
| `binary` | ✅ 利用可能 | バイナリデータ生成 |
| `cocos` | ✅ 利用可能 | Cocos プラットフォームコード生成 |
| `typescript` | ✅ 利用可能 | TypeScript コード生成 |
| `dejavu` | ✅ 利用可能 | テンプレートエンジンコード生成 |
| `unity` | ⚠️ 無効 | Unity プラットフォームコード生成（リファクタリング中） |
| `xlua` | 開発中 | XLua スクリプトコード生成 |
| `sql` | 開発中 | SQL データベースコード生成 |
| `xml` | 開発中 | XML データ生成 |

## クロスプラットフォームサポート

XCell はクロスプラットフォームで設計されており、異なるプラットフォーム間で設定データを共有し、データの一貫性と開発効率を確保します。

### プラットフォーム間データ共有

- 統一されたデータモデル
- クロスプラットフォーム型マッピング
- 標準化された設定フォーマット

### ベストプラクティス

- ターゲットプラットフォームに応じて適切なデータフォーマットを選択
- 表結合ルールでクロスプラットフォームデータを管理
- 各プラットフォームのデータ構造を定期的に同期
