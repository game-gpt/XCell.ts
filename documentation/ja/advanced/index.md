## マルチエンジンサポート

XCell の設計理念は、すべてのゲームエンジンに優れた設定表管理ソリューションを提供することです：

- **Unity (C#)**: 完全な組み込みサポート
- **Cocos Creator**: JSON/XML + TypeScript/Lua ローダー経由
- **Godot**: JSON + GDScript ローダー経由
- **Unreal Engine**: バイナリ + C++ ローダー経由
- **カスタムエンジン**: 拡張性ドキュメントを通じてカスタムエクスポーターを作成

## 前提条件

このセクションのドキュメントを読む前に、以下のことをお勧めします：

1. XCell の基本的な使用方法に精通していること
2. プロジェクト設定ファイル `XCell.toml` の基本構造を理解していること
3. ターゲット言語のプログラミング基礎（Rust、C#、C++、Python、Lua、TypeScript など）を持っていること
