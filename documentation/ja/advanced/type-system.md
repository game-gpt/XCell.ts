# 型システム（Type System）

XCell は複数のデータ型をサポートし、標準型は Rust 規約を採用し、C 規約と C++ 規約とも互換性があります。型は大文字と小文字を区別しません。

## 基本型

### 整数型

| 標準記法  | Unity 規約             | Unreal 規約  | 説明       | 範囲                                         |
| ----- | -------------------- | ---------- | -------- | ------------------------------------------ |
| `i8`  | `char`               | `int8_t`   | 8ビット符号付き整数  | -128 ～ 127                                 |
| `u8`  | `unsigned char`      | `uint8_t`  | 8ビット符号なし整数  | 0 ～ 255                                    |
| `i16` | `short`              | `int16_t`  | 16ビット符号付き整数 | -32768 ～ 32767                             |
| `u16` | `unsigned short`     | `uint16_t` | 16ビット符号なし整数 | 0 ～ 65535                                  |
| `i32` | `int`                | `int32_t`  | 32ビット符号付き整数 | -2147483648 ～ 2147483647                   |
| `u32` | `unsigned int`       | `uint32_t` | 32ビット符号なし整数 | 0 ～ 4294967295                             |
| `i64` | `long long`          | `int64_t`  | 64ビット符号付き整数 | -9223372036854775808 ～ 9223372036854775807 |
| `u64` | `unsigned long long` | `uint64_t` | 64ビット符号なし整数 | 0 ～ 18446744073709551615                   |

## 複合型

### 配列とベクトル型

**異なる型の規約**：

| 標準記法        | C# 規約            | 説明         |
| ----------- | ---------------- | ---------- |
| `[T]`       | `T[]`            | 動的配列       |
| `[T; N]`    | `T[N]`           | 静的配列（固定サイズ） |
| `Vec<T>`    | `List<T>`        | ベクトル/リスト型    |
| `vec2<f32>` | `Vector2<float>` | 2Dベクトル       |
| `vec3<f32>` | `Vector3<float>` | 3Dベクトル       |
| `vec4<f32>` | `Vector4<float>` | 4Dベクトル       |

**説明**：

- 動的配列 `[T]` とベクトル `Vec<T>` は可変数の要素を格納
- 静的配列 `[T; N]` は固定数の要素を格納、長さは定義時に決定
- 特殊ベクトル型（vec2/vec3/vec4）はグラフィックスプログラミングでよく使用され、Unity などのエンジンでは特定のパフォーマンス最適化がある

**例**：

- `[i32; 5]` - 5つの i32 要素を含む静的配列
- `[string]` - 動的サイズの文字列配列
- `Vec<i32>` - 整数ベクトル
- `vec3<f32>` - 3D浮動小数点ベクトル

### 辞書型

**フォーマット**：`HashMap<K, V>` または `dict<K, V>`

**例**：

- `HashMap<string, i32>` - 文字列から整数へのマッピング
- `dict<i32, string>` - 整数から文字列へのマッピング

### タプル型

**フォーマット**：`(T1, T2, ...)`

**例**：

- `(i32, string)` - 整数と文字列を含むタプル
- `(f32, f32, bool)` - 2つの浮動小数点数と1つのブール値を含むタプル

## 一意型と主キー

**一意型フォーマット**：

- `@T` - そのフィールドの値が表内で一意である必要があることを示す、つまり表内で2行のデータがそのフィールドで同じ値を持つことはできない
- `@@T` - そのフィールドの値が表内で一意であり、主キーとして機能することを示す

**主キーの説明**：

- 主キーは表内の各行データを一意に識別するためのフィールド
- 表で `@@T` を使用して主キーを明示的にマークしていない場合、表の最初の列が自動的に主キーとして扱われる
- 主キー値は一意で null 以外である必要があり、表間の関連付けに使用される

**例**：

- `@@i32` - 整数型の主キーフィールド
- `@string` - 文字列型の一意フィールド（主キーではない）

## カスタム型

### 列挙型

Enumerate 表で定義された列挙型は他の表で使用できます。

**例**：

- `QualityType` - 列挙表で定義された品質タイプを参照

### 構造体型

Class 表で定義された構造体型は他の表で使用できます。

**例**：

- `Position` - Class 表で定義された位置構造体を参照

## 型変換

XCell は自動的な型変換をサポート、例えば：

- 整数は自動的に浮動小数点数に変換可能
- 浮動小数点数は必要に応じて整数に変換可能（小数部分は切り捨て）
- 数値は文字列に変換可能
- 文字列は適切な場合に数値に変換可能

## 型検証

XCell は表を解析する際に型検証を行い、データが指定された型要件に準拠していることを確認します。型が一致しない場合、コンパイル時にエラーが生成されます。
