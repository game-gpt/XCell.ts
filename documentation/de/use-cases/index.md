# Anwendungsfälle

Diese Seite enthält Verwendungsbeispiele und Best Practices für XCell in verschiedenen Szenarien.

## Verfügbare Fälle

- [Unity-Integration](unity-integration.md) - Integration von XCell mit der Unity-Spielengine

## Fallbeschreibungen

### Unity-Integration

Geeignet für Entwickler, die die Unity-Engine für die Spielentwicklung verwenden. Dieser Fall beschreibt detailliert, wie das XCell-Konfigurationstabellen-Verwaltungstool nahtlos in Unity-Projekte integriert wird, einschließlich:

- Unity-Projektkonfiguration
- Erstellung und Verwaltung von Konfigurationstabellen
- C#-Codegenerierung
- Binärdatenladen
- Laufzeitverwendungsbeispiele
